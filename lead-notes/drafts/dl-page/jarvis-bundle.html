Jarvis-sikkerhetskopi

Filen med alt som er bygget (14 grener), og kommandoene som legger den på GitHub fra PC-en din. Siden er privat og kan slettes etterpå.

1Last ned filen

Åpne denne siden i nettleseren på PC-en (ikke på mobilen). Trykk knappen og bekreft i dialogen som kommer.

Sjekker om nedlasting er mulig ...

Filen havner vanligvis i Nedlastinger. Du trenger ikke pakke den ut selv; blokken i trinn 2 gjør det.

2Lim inn i PowerShell

Åpne PowerShell, kopier hele blokken under og lim den inn. Hver git push skal vise [new branch]. Skriv inn GitHub-innlogging hvis nettleseren spør.

cd $HOME\jarvisbuild
$zip = Get-ChildItem $HOME -Recurse -Filter "jarvis-bundle-b*.zip" -ErrorAction SilentlyContinue | Select-Object -First 1 -ExpandProperty FullName
$dir = Join-Path $env:TEMP "jarvis-bundle-b"
Expand-Archive $zip -DestinationPath $dir -Force
$b = Join-Path $dir "local-only-2026-11-22b.bundle"
git bundle verify $b
git fetch $b 'refs/heads/*:refs/remotes/bundle/*'
git push origin refs/remotes/bundle/claude/wp-k-ledger-rester:refs/heads/claude/wp-k-ledger-rester
git push origin refs/remotes/bundle/claude/wp-h1-control-centers:refs/heads/claude/wp-h1-control-centers
git push origin refs/remotes/bundle/claude/wp-i-connector-sdk:refs/heads/claude/wp-i-connector-sdk

Blokken bruker aldri --force og endrer ikke main. Står klonen din et annet sted enn C:\Users\Tobia\jarvisbuild, bytt ut første linje med cd til den mappen.

3Sjekk og si fra

Kjør linjen under. Du skal se 14 grener. Skriv deretter «pushet» i chatten med Claude, eller lim inn det som står hvis noe feilet.

git ls-remote --heads origin "claude/wp-*" "claude/d471-d474-konsolidering" "claude/lead-notes-2026-11"
